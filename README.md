# Stream Diffusion RS

Stream diffusion implementation in Rust using Burn framework. High-performance AI image generation with real-time streaming capabilities.

## Features

- Burn ML framework integration
- Real-time streaming diffusion
- GPU acceleration support
- High-performance image generation
- Modular model architecture

## Building

```bash
cargo build --release
```

## Usage

This library provides a high-performance implementation of stream diffusion for AI image generation. It uses the Burn framework for efficient GPU acceleration and supports real-time streaming of generated images.
